# Gennety Canvas // AI Agent Bridge & Model Context Protocol (MCP) Guide

Этот документ описывает, как подключить искусственный интеллект (Claude Desktop, Cursor, Antigravity, ChatGPT, Aside Browser и автономные скрипты) к вашему личному аккаунту в **Gennety Canvas**, чтобы агент мог:
1. Автономно изучать структуру ваших проектов и папок.
2. Контекстно-релевантно понимать необычную семантику графа удержания (Retention Flywheel, 8 категорий, аппаратные маяки, gym-subscription habit loop).
3. Искать карточки, метрики и результаты по всем папкам.
4. Проводить глубокий аудит связей, выявлять тупики и находить точки оттока.
5. Обсуждать архитектуру в чате и предлагать обновления в готовом JSON-формате.

Самый быстрый способ для **ChatGPT (GPT-4o)**, **Claude (Web / App)**, **Antigravity** или **Cursor Composer**:

1. Откройте приложение **Gennety Canvas** (локально или на [gennety-retention-canvas.vercel.app](https://gennety-retention-canvas.vercel.app)).

3. Нажмите **«Скопировать промпт»**.
4. Вставьте скопированный текст в диалог с любым AI-агентом.

## 🔌 Способ 2: Настоящий MCP-Сервер v2.0 (Model Context Protocol)

В репозиторий встроен полноценный MCP-сервер v2.0 на чистом Node.js (без тяжелых внешних зависимостей), работающий по стандарту JSON-RPC 2.0 через `stdio`. Сервер оснащен **движком математического позиционирования** и **автоматической синхронизацией с облачным аккаунтом** (любые созданные карточки сразу отображаются на живом сайте).

### 12 специализированных инструментов (Tools):

#### 🏗️ Генерация комплексных архитектур и выравнивание
1. **`build_explanatory_workflow`** — **Флагманский инструмент**. Создает полноценный объяснительный воркфлоу в 1 вызов. Принимает шаги воронки (`stages`), сопутствующие фото/макеты (`photos`), объяснительные текстовые блоки (`textNotes`) и связи (`edges`). Раскладывает их с математически выверенными отступами:
   - Режим `horizontal_tracks` (3 параллельные визуальные дорожки: Фото на `y=80`, Стратегия на `y=380`, Текстовые заметки на `y=680`).
   - Режим `stage_columns` (колонки стадий `x = 80 + col * 460px` со структурированными плашками).
2. **`auto_layout_project`** — Автоматически наводит порядок на холсте любого проекта. Выравнивает существующие разрозненные карточки по ровным строкам, колонкам или дорожкам без наложений и с идеальными отступами.

#### 🧩 Создание и редактирование контента холста
3. **`create_text_block`** — Добавляет на холст **отдельный текстовый блок** (заметку, продуктовую гипотезу, комментарий команды или формулу). Поддерживает выбор цвета (`amber`, `emerald`, `blue`, `rose`, `purple`, `graphite`, `default`), размер шрифта и относительное позиционирование (`relativeToNodeId`, `placement: 'above' | 'below' | 'right' | 'left'`).
4. **`create_photo_card`** — Добавляет **фото-карточку / макет экрана** (`imageNode`) с изображением, заголовком, подписью и настраиваемой шириной. Может автоматически размещаться над соответствующей стратегической карточкой (`placement: 'above'`).
5. **`create_or_update_node`** — Универсальное создание или редактирование узла любого типа (`strategyNode`, `textNode`, `imageNode`) с авто-расчетом свободных координат или точным позиционированием.
6. **`create_or_update_edge`** — Добавление или обновление направленной связи между любыми блоками холста с подписью (`label`), типом кривой (`bezier`, `smoothstep`, `straight`) и анимацией потока.

#### 🔍 Аналитика и исследование
7. **`analyze_retention_flow`** — Автоматический продуктовый аудит воронки:
   - Проверка наличия замкнутого маховика (Flywheel Loop).
   - Поиск изолированных узлов (без связей).
   - Поиск тупиковых веток (не доходящих до `outcome`).
   - Аудит покрытия ключевых стратегических категорий.
   - Выявление шагов без целевых метрик (`keyMetric`) и результатов (`outcome`).
8. **`list_projects`** — Возвращает список всех проектов аккаунта с количеством узлов, связей, тегами и датами изменения.
9. **`get_project_canvas`** — Полный дамп схемы: все карточки стратегии, фото-карточки, объяснительные блоки и связи с их координатами.
10. **`search_canvas`** — Мгновенный поиск по текстам, заметкам, метрикам, тегам и заголовкам во всех проектах.

#### 🔄 Синхронизация и безопасность
11. **`fetch_remote_account`** — Синхронизирует данные из облачного REST API по ключу доступа в локальное хранилище.
12. **`export_workspace_backup`** — Полный JSON-бэкап аккаунта со всеми холстами и рисунками.

```json
{
  "mcpServers": {
    "gennety-canvas": {
      "command": "node",
      "args": ["/Users/pro/Desktop/Gennety Canvas/mcp/index.js"],
      "env": {
        "GENNETY_ACCESS_KEY": "ВАШ_КЛЮЧ_ДОСТУПА"
      }
    }
  }
}
```

Перезапустите Claude Desktop. В чате появится иконка молотка 🔨 со всеми инструментами Gennety Canvas!

## 🌐 Способ 3: Автономный агент с браузером (Aside Browser / Playwright / DevTools)

Если вы используете агента с браузерным модулем (например, навык **Aside Browser**):

### 1. Авторизация по URL в 1 клик
Передайте агенту команду открыть страницу:
```
https://gennety-retention-canvas.vercel.app/?key=ВАШ_КЛЮЧ_ДОСТУПА
```
Приложение считывает параметр `?key=` из URL, валидирует его, сохраняет сессию и сразу отображает рабочий стол вашего личного кабинета.

### 2. Доступ к JavaScript API в консоли браузера
В глобальной области видимости `window` зарегистрирован интерфейс:
```javascript
// Получить полный снимок воркспейса (все проекты, узлы, связи):
const data = window.__GENNETY_WORKSPACE__.exportFullSnapshot();
console.log(data);

// Поиск карточек по ключевым словам:
const results = window.__GENNETY_WORKSPACE__.searchNodes('hardware');

// Получить текущий активный проект:
const active = window.__GENNETY_WORKSPACE__.getActiveProject();
```

### 3. Прямой REST API (JSON без браузера)
```bash
curl -X GET "https://gennety-retention-canvas.vercel.app/api/workspace?key=ВАШ_КЛЮЧ_ДОСТУПА" \
  -H "Accept: application/json"
```

В режиме локальной разработки (`npm run dev`) запрос автоматически обращается к локальному файлу `workspace-storage.json`:
```bash
curl -X GET "http://localhost:5173/api/workspace?key=ВАШ_КЛЮЧ_ДОСТУПА"
```
