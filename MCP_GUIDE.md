# Gennety Canvas // AI Agent Bridge & Model Context Protocol (MCP) Guide

Этот документ описывает, как подключить искусственный интеллект (Claude Desktop, Cursor, Antigravity, ChatGPT, Aside Browser и автономные скрипты) к вашему личному аккаунту в **Gennety Canvas**, чтобы агент мог:
1. Автономно изучать структуру ваших проектов и папок.
2. Контекстно-релевантно понимать необычную семантику графа удержания (Retention Flywheel, 8 категорий, аппаратные маяки, gym-subscription habit loop).
3. Искать карточки, метрики и результаты по всем папкам.
4. Проводить глубокий аудит связей, выявлять тупики и находить точки оттока.
5. Обсуждать архитектуру в чате и предлагать обновления в готовом JSON-формате.

---

## ⚡ Способ 1: Единый Master AI-Промпт (В 1 клик)

Самый быстрый способ для **ChatGPT (GPT-4o)**, **Claude (Web / App)**, **Antigravity** или **Cursor Composer**:

1. Откройте приложение **Gennety Canvas** (локально или на [gennety-retention-canvas.vercel.app](https://gennety-retention-canvas.vercel.app)).
2. Нажмите кнопку **«AI & MCP»** в верхнем правом углу (или нажмите горячую клавишу `⌘J` / `Ctrl+J`).
3. Нажмите **«Скопировать промпт»**.
4. Вставьте скопированный текст в диалог с любым AI-агентом.

### Что содержит этот сгенерированный промпт?
- **Прямую ссылку для 1-Click автовхода**: `https://gennety-retention-canvas.vercel.app/?key=ВАШ_КЛЮЧ` (страница сразу открывает ваш аккаунт без ручного ввода).
- **Ваш персональный ключ доступа** (`GNTY-XXXX-XXXX-XXXX`).
- **REST API URL**: `https://gennety-retention-canvas.vercel.app/api/workspace?key=ВАШ_КЛЮЧ`.
- **Руководство по семантике графа**: расшифровка всех 8 категорий (`foundation`, `psychology`, `hardware`, `retention`, `event`, `lifecycle`, `outcome`, `custom`), роли аппаратного маркера и циклов привычки.
- **Сводку по всем вашим проектам и папкам** (названия, ID, число узлов, связей, теги, даты изменения).
- **Полный структурированный дамп активного проекта** со всеми карточками, описаниями, метриками (`keyMetric`), результатами (`outcome`) и связями.
- **Инструкции роли для агента**: отвечать как Senior Retention Architect, анализировать циклы, искать узкие места и генерировать валидный JSON для мгновенного импорта через `⌘I`.

## 🔌 Способ 2: Настоящий MCP-Сервер (Model Context Protocol)

В репозиторий встроен полноценный MCP-сервер на чистом Node.js (без тяжелых внешних зависимостей), работающий по стандарту JSON-RPC 2.0 через `stdio`.

### Инструменты (Tools), доступные агенту через MCP:
1. `list_projects` — Возвращает список всех проектов аккаунта с количеством узлов, связей, тегами и метаданными.
2. `get_project_canvas` — Возвращает полную структуру схемы (узлы, категории, метрики, переходы, связи) по ID или для активного проекта.
3. `search_canvas` — Полнотекстовый и категориальный поиск по карточкам, тегам, метрикам и описаниям во всех проектах.
4. `analyze_retention_flow` — Автоматический стратегический аудит схемы:
   - Проверка наличия замкнутого маховика (Flywheel Loop).
   - Поиск изолированных узлов (без связей).
   - Поиск тупиковых веток (не доходящих до `outcome`).
   - Аудит покрытия всех 7 ключевых стратегических категорий.
   - Выявление шагов без целевых метрик (`keyMetric`) и результатов (`outcome`).
5. `create_or_update_node` — Позволяет агенту самому добавлять новые карточки или редактировать существующие в вашем проекте!
6. `fetch_remote_account` — Синхронизирует данные из удаленного REST API по ключу доступа в локальное хранилище.
7. `export_workspace_backup` — Полный JSON-бэкап аккаунта.

### Подключение к Claude Desktop

Откройте файл настроек Claude Desktop:
`~/Library/Application Support/Claude/claude_desktop_config.json` (на macOS)

Добавьте блок в секцию `mcpServers`:

```json
{
  "mcpServers": {
    "gennety-canvas": {
      "command": "node",
      "args": ["/Users/pro/Desktop/Gennety Canvas/mcp/index.js"],
      "env": {
        "GENNETY_ACCESS_KEY": "ВАШ_КЛЮЧ_ДОСТУПА"
      }
    }
  }
}
```

Перезапустите Claude Desktop. В чате появится иконка молотка 🔨 со всеми инструментами Gennety Canvas!

## 🌐 Способ 3: Автономный агент с браузером (Aside Browser / Playwright / DevTools)

Если вы используете агента с браузерным модулем (например, навык **Aside Browser**):

### 1. Авторизация по URL в 1 клик
Передайте агенту команду открыть страницу:
```
https://gennety-retention-canvas.vercel.app/?key=ВАШ_КЛЮЧ_ДОСТУПА
```
Приложение считывает параметр `?key=` из URL, валидирует его, сохраняет сессию и сразу отображает рабочий стол вашего личного кабинета.

### 2. Доступ к JavaScript API в консоли браузера
В глобальной области видимости `window` зарегистрирован интерфейс:
```javascript
// Получить полный снимок воркспейса (все проекты, узлы, связи):
const data = window.__GENNETY_WORKSPACE__.exportFullSnapshot();
console.log(data);

// Поиск карточек по ключевым словам:
const results = window.__GENNETY_WORKSPACE__.searchNodes('hardware');

// Получить текущий активный проект:
const active = window.__GENNETY_WORKSPACE__.getActiveProject();
```

### 3. Прямой REST API (JSON без браузера)
```bash
curl -X GET "https://gennety-retention-canvas.vercel.app/api/workspace?key=ВАШ_КЛЮЧ_ДОСТУПА" \
  -H "Accept: application/json"
```

В режиме локальной разработки (`npm run dev`) запрос автоматически обращается к локальному файлу `workspace-storage.json`:
```bash
curl -X GET "http://localhost:5173/api/workspace?key=ВАШ_КЛЮЧ_ДОСТУПА"
```
